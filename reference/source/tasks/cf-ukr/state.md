# Состояние: CF на украинском

Цель: вся карта CF mod на украинском (просьба владельца 2026-11-18).
База: релиз v16 (Maps\cf\CastleFight_mod_v16.w3x), сборка castle-fight\build_cf.py.
Решения владельца: две карты; русская v16 остаётся, украинская отдельным файлом в Maps\cf_ua (там одна текущая). Всё переводить по максимуму. Правила проекта: ничего не удалять, бэкапы *.bak-ДАТА.
Меню клиента игры картой не меняется; стандартные юниты/умения без правок в карте надо добавить в объекты с украинским именем (этап 4).
