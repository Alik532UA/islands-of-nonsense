# 03. Карта файлов архива

## `data/` (готовые данные, начинай с них)

Сгенерированы `source/castle-fight/export_data.py` из карты `maps/CastleFight_mod_v37.w3x` (русская версия, названия на русском).

| Файл | Содержимое | Записей |
|---|---|---|
| `races.json` | Расы: название, id строителя (у Сборщиков «модовый строитель»), список id зданий | 11 |
| `buildings.json` | Здания: `id`, `name`, `gold`, `unit` (какого бойца тренирует), `upgrade_from`, `upgrade_extra_cost`, `race`, `raw_fields` | 102 |
| `units.json` | Бойцы: `hp`, `armor`, `armor_type`, `attack_type`, `damage_*`, `cooldown`, `range`, `move_type`, `flying`, `base_unit` (стандартный юнит Warcraft III, на основе которого создан), `raw_fields` | 102 |
| `items_ids.json` | id предметов, которые обрабатывает наш скрипт (только id, названия смотри в `build_cf.py` и `.wts`) | несколько |
| `jass_constants.json` | Несколько констант оригинала (`Dx` 0.2, `ea` 0.18, `To` 0.08, `Ve` 60, `Wv` 50, `ie` 15) | |

Замечания: у 12 бойцов нет своего имени в карте (стандартные юниты Warcraft III: `h03B` Footman-основа и т.д.), в `name` лежит их id или имя из строк карты. 6 зданий без расы (`race: null`): расу не удалось восстановить скриптом (они принадлежат расам по ссылкам в оригинальном скрипте).

## `maps/`

- `CastleFight_mod_v37.w3x`: релиз мода, русский.
- `CastleFight_mod_v37_ua.w3x`: тот же, украинский.
Это MPQ-архивы. Открыть: MPQ Editor, WinMPQ, или StormLib. Внутри `war3map.w3e` (ландшафт), `war3map.wpm` (проходимость), `war3map.w3r` (регионы: прямоугольники зон строительства и дорог, мы их не разбирали), `war3map.w3i` (параметры карты), `war3map.j` (скрипт).

## `source/castle-fight/` (код мода)

| Файл | Роль |
|---|---|
| `build_cf.py` | Главная сборка мода (2345 строк): правки объектов и скрипта, тесты. Начинай с комментариев-заголовков `# 1)`, `# 2)`... |
| `bot_ai.py` | JASS ботов (кузница, умения, защита, лог) в виде Python-строк; `GLOBALS`, `INIT` |
| `skills_jass.py` | JASS умений рас (баффы, замедление, чума, мина, заражение) |
| `race_sbor.py` | Данные расы «Сборщики» (юниты, здания, улучшения, тексты RU и UA) |
| `race_sbor_jass.py` | JASS расы «Сборщики»: обломки, умение «Великая сборка», особые здания |
| `race_sbor_ua.json` | Украинские тексты расы |
| `cfobj.py` | Чтение/запись `w3u/w3a/w3t` без потерь, базовые статы из SLK |
| `analyze.py` | Таблица силы рас («сила на золото») → `power.json` |
| `export_data.py` | Выгрузка данных в `data/*.json` (этот архив) |
| `tools_slk.py` | Достаёт SLK из MPQ игры |
| `orig_war3map.j` | Скрипт оригинальной карты 1.17 (359 КБ, обфусцирован) |
| `war3map.j` | Скрипт собранного мода (последняя собранная версия; смотри как выглядит итог) |
| `ПЛАН.md` | Первоначальный план переделки с описанием оригинала |
| `changes.txt` | Список правок баланса (какие юниты и как изменены) |
| `power.json` | Таблица силы рас (сырая, имена `TRIGSTR_N`; чистая версия в `data/`) |
| `_econ.py`, `_econ2.py` | Модель экономики (рабочие прикидки) |
| `_run_when_free.ps1`, `_showlog.py`, `_close.ps1` | Запуск автотеста в игре и чтение лога |
| `slk/` | Таблицы базовых юнитов Warcraft III (`UnitBalance`, `UnitWeapons`, `UnitData`) |

## `source/wc3-td/build/`

`make_base.py` (обёртка StormLib) и `gen.py` (помощники объектов). Это библиотеки проекта TD (другая карта), но `build_cf.py` импортирует их. Для понимания Castle Fight читать не обязательно.

## `source/tasks/`

- `cf-commanders/spec.md`: спека командиров друзей.
- `cf-items-race/`: план и состояние задачи «предметы и раса Сборщики» (`plan.md`, `plan_v2.md`, `state.md`).
- `cf-ukr/`: украинская версия: `build_ua.py` (сборка), `_tr.py` (движок перевода), словари `_dict_*.py`, `_new_ua.py` (новые строки), `_abil_ua.py` (умения), `_base_ua.py`/`_basenames.py` (имена стандартных юнитов), `_extract.py` (выгрузка строк карты), `_scratch/` (разовые скрипты правок и разведки, можно не читать), `plan.md`, `state.md`.

## `source/tools/`

`preflight.py` (автопроверка перед сборкой), `stable_snapshot.py` (утверждение рабочей версии, нужен репозиторий, которого в архиве нет).

## `notes/`

- `ЗНАНИЯ.md`: длинные заметки по ходу работы (структура файлов карты, грабли, уроки каждой версии). Часть про другие карты (BvO, Legion TD) не относится к Castle Fight, можно пропускать.
- `ЧЕКЛИСТ_СБОРКИ_И_ТЕСТА.md`: чеклист сборки и теста.
